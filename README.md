# São Braz — Website

A React-based website project featuring interactive frontend components and 3D-related libraries.

## Tech stack

- React 18 and React Router
- Three.js, React Three Fiber and Drei
- GSAP animations
- Swiper
- Font Awesome
- Create React App

## Getting started

Install Node.js and npm, then run:

```bash
npm install
npm start
```

The development server normally opens at `http://localhost:3000`.

To generate a production build:

```bash
npm run build
```

## Repository structure

- `src/pages/` — application pages
- `src/components/` — reusable UI components
- `src/assets/` — application assets
- `public/` — public files

## Deployment notes

The package configuration contains a GitHub Pages deployment script (`npm run deploy`). Verify the `homepage` setting and deployment configuration after repository renames before publishing.
